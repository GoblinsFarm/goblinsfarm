CoC Bot BlueStacks Setup, From Zero to Farming

Updated: 24 August 2026

Every serious Clash of Clans bot runs the game inside an Android emulator and controls it from the outside. This tutorial takes you from a bare computer to a farming session in five steps: BlueStacks, Clash of Clans, Goblins Farm, the setup wizard, Start. The honest pitch up front: the old generation of bots made Clash of Clans bot emulator setup a weekend project, ADB paths, OCR libraries, resolution profiles, config files. Goblins Farm's setup wizard does all of that automatically, so the manual part of this guide is genuinely short.

What you need

  • A Windows PC or a Mac (the macOS app is code-signed and notarized, so it opens without security workarounds)
  • BlueStacks, the free Android emulator
  • A Clash of Clans account signed into Supercell ID (so you can load your village in the emulator)
  • Goblins Farm, the bot itself

That's the whole list. Goblins Farm bundles its own ADB, ffmpeg, and Tesseract, so there is nothing else to download, no PATH to edit, no dependencies to hunt down.

Step 1, Install BlueStacks

Download BlueStacks from its official site and run the installer. It's free. Once it's installed, open it and let it finish its first-run setup.

One setting worth doing now: open BlueStacks' display settings and set the resolution to 2560x1440. Goblins Farm reads the emulator screen with computer vision, template matching and OCR, and this is the recommended resolution for reliable detection. The wizard will flag it later if it's off, but setting it now saves a round trip.

Step 2, Install Clash of Clans inside BlueStacks

Inside BlueStacks, sign into the Google Play Store, search for Clash of Clans, and install it, exactly as you would on a phone.

Step 3, Sign into your village

Open Clash of Clans in the emulator and sign in with your Supercell ID to load your village. Play a minute or two manually to confirm everything runs smoothly. Two quick checks that help the bot later:

  • Game language: English. The bot's OCR reads on-screen text, and English is what it's trained on.
  • Dismiss any one-time popups (events, offers) so the village screen is clean.

Step 4, Install Goblins Farm and run the wizard

On macOS: open the .dmg and drag Goblins Farm to Applications. The app is signed and notarized, no right-click-open dance, no Gatekeeper warnings. On Windows: run the installer. Either way, the app checks for updates on every launch, so you're always on the current version without reinstalling.

First launch starts the setup wizard, and this is where the old-bot pain disappears:

  1. The wizard auto-detects ADB and your running emulator, no ports, no paths, no "adb devices" in a terminal.
  2. It checks the emulator resolution and tells you if it needs the recommended 2560x1440.
  3. It confirms it can see the game screen and send taps.

Keep BlueStacks open with Clash of Clans running while the wizard does its checks. When it finishes, the bot is connected.

Step 5, Set targets and press Start

In the Farm tab, set your loot targets with the sliders, gold, elixir, and dark elixir. The bot searches for bases, skips ones below your loot thresholds, deploys troops, collects, and repeats until the targets are hit, then stops automatically. Details on picking good thresholds are in the farming bot guide. If you have the Builder Base license, the night village mode runs its own loop with its own stop conditions.

Optional but recommended: open Settings and scan the QR code to link phone notifications. You'll get pushes when farming starts, when loot targets are hit, and if anything goes wrong, with Stop/Start/Status buttons right in the notification.

Troubleshooting

Emulator not detected

The wizard finds BlueStacks over ADB automatically, so if it can't, the usual cause is that the emulator isn't fully started. Make sure BlueStacks is open and past its loading screen before running the wizard, then retry the detection step. A restart of BlueStacks (fully quit, reopen) clears most one-off ADB glitches. If another Android tool on your machine is holding the ADB connection, close it, Goblins Farm uses its own bundled ADB and just needs the emulator free to talk to.

Wrong resolution / bot misclicks

If the bot taps slightly off-target or fails to find buttons, check the emulator resolution first. Set BlueStacks to 2560x1440 in its display settings, restart the emulator, and run the wizard again so it re-verifies the screen.

Text not being read / loot amounts wrong

Set the game language to English in Clash of Clans' in-game settings. OCR reads the loot numbers and button labels on screen, and other languages change both the fonts and the words it expects.
