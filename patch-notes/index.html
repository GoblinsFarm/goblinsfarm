Clash of Clans Patch Notes

Build by build

Home›Patch notes

Updated: 18 September 2026

Supercell's patch notes say what they chose to announce. This says what the game files actually hold. Every entry compares two client builds cell by cell, so you can see which numbers moved, which pages are new, and which of our own figures were wrong.

What this is

Every stat table on this wiki is read from a specific, recorded Clash of Clans client build. When a newer build appears we read it again and the whole site regenerates. This section is the difference between the two, computed rather than written: entries added, entries dropped, and every cell in every level table that is not what it was.

It is deliberately narrower than an official patch note. It cannot see anything that is not in the files — matchmaking tweaks, event schedules, bug fixes — and it does not try to. What it can do is tell you exactly which numbers on this site changed under your feet, including the ones that changed because we had them wrong.

How to follow it

There is an RSS feed for this section, same as the news and the blog. Nothing is posted between builds, so subscribing to it is a quiet way to hear when the numbers you are planning an upgrade around have moved.

Frequently asked

Is this Supercell's official patch notes?

No. Supercell publishes its own release notes and those are the authority on what an update is meant to do. This is a mechanical comparison of two builds of the game's data files, which catches things release notes leave out and misses everything that is not a number.

Why do some entries say a value was corrected rather than changed?

Because the diff cannot tell a rebalance from our own mistake, and both look identical in a table. Where we know a change came from fixing how we read the files rather than from Supercell changing them, it says so in the post.

How quickly does this appear after an update?

As soon as we read the new build. There is no public endpoint that announces a new client build, so it is found by checking, and a post here means the whole wiki has already been regenerated against it.
